# ST 分类器

用于保存角色卡常用配置，并给 SillyTavern 美化添加标签和筛选。

## 预设绑定保存修复

- 保存和更新固定使用点击时的预设名称及条目顺序，输入名称或确认期间发生预设切换也不会保存成另一个预设。
- 更新期间切换角色会停止写入；确认时重新读取绑定列表，保留期间的其他改动。
- 当前接口预设列表未就绪时不再读取其他接口的预设；数字预设名称也按名称匹配，避免误选列表编号相同的预设。

## 1.0.1 启动与兼容修复

- 修复首次安装、尚无分类器配置时启动报错的问题，保留原有标签、收藏和角色绑定数据。
- 酒馆接口改为动态加载，并优先使用公开上下文；用户名、头像、预设管理器和世界书列表始终读取最新状态。
- 等待酒馆就绪后再初始化。脚本或样式加载失败会显示原因及重试按钮；TT 重新挂载设置面板后会恢复分类器控件。
- 预设按名称匹配，避免列表重排后因旧编号选错；切换等待原生完成事件，再应用条目顺序，保存超时可重试。
- 自动绑定失败不会被标记为已完成，快速切卡时停止后续应用；已完成的自动绑定不会覆盖之后手动选择的预设。
- 角色卡字段和完整世界书保存后重新读取核对，未确认完整应用时明确提示；重试不会仅凭内存缓存误报成功。

开发验证：

- `node --test tests/compatibility.test.mjs`：配置与接口适配单元测试。
- `node --test tests/preset-bindings.test.mjs`：预设保存、更新、取消、切卡和名称匹配回归测试。
- `node tests/browser-compatibility.mjs`：模拟普通酒馆和 TT 接口的隔离浏览器回归，含失败重试、切卡保护、旧数据与移动端宽度场景。
- `node tests/native-smoke.mjs`：复制本地 SillyTavern 程序及默认资源到临时目录，以真实前后端接口验证首次启动、标签/角色绑定保存、预设/user 和世界书恢复；不复制用户数据或现有配置，结束后清理临时副本。

浏览器测试需要 Chrome 或 Edge，可用 `TAC_TEST_CHROME` 指定路径。真实酒馆测试默认使用本扩展所在的 SillyTavern 程序，也可用 `TAC_TEST_ST_ROOT` 指定源码目录（需已安装 `node_modules`）。上述测试不操作现有角色卡或设置；手机 TT 实机仍需复测。

## 角色卡分类器

打开一张角色卡后，在扩展设置中展开 **美化与角色绑定**。

### 保存分类

- **美化绑定**：切换到需要的美化后点 **添加**，无需命名；可以为同一张角色卡添加多个美化。
- **预设绑定**：先选好当前预设和条目顺序，再点 **保存**，输入一个方便识别的名称。
- **user 绑定**：先切换到需要的 user 名称和头像，再点 **保存**。
- **世界书绑定**：先启用需要的全局世界书和角色世界书，再点 **保存**。保存内容包含当前选择和世界书条目。
- 预设、user 和世界书绑定右侧可手动应用或删除；预设和世界书还可以用旋转箭头更新为当前配置。
- 美化绑定提供应用、删除和星标操作；点击应用会立即切换美化，星标决定切换角色卡时自动加载哪一个美化。

### 自动加载

点击绑定右侧的空心星标，即可把它标为当前角色卡的自动加载项；星标变为实心后生效。以后切换到这张角色卡时，会自动加载已标记的美化、预设、user 和世界书。

每一类只能标记一个自动加载项。再次点击实心星标即可取消。

### 角色卡关联

点击 **角色卡关联** 右侧的 `+`，可以从角色卡库添加关联角色。搜索框支持按角色名称筛选，点击角色卡即可添加。

关联添加成功后会弹出内容转移窗口，可以将当前角色卡的美化、预设、世界书或 user 信息合并到新关联的角色卡。目标卡已有内容不会被覆盖，也不会重复添加相同内容；世界书仅转移非角色绑定世界书中的条目，应用时也会保留目标卡自己的角色绑定世界书。

## 美化分类

在 SillyTavern 的美化选择区域可以看到以下 4 个按钮：

| 按钮 | 作用 |
| --- | --- |
| **保存** | 用当前界面设置覆盖保存正在使用的美化。 |
| **重命名** | 修改当前美化的名称。 |
| **另存为** | 把当前界面设置保存成一个新的美化，不覆盖原美化。 |
| **打标签** | 给当前美化添加、移除或管理标签，也可以收藏当前美化。 |

### 添加和删除标签

1. 选择一个美化，点击 **打标签**。
2. 在 **风格** 或 **主题** 中输入文字，按回车或点击 `+` 添加。
3. **颜色** 和 **头像** 标签会由扩展自动识别，也可以在标签窗口中手动选择。
4. 点击当前美化已有的标签，只会从当前美化移除；长按标签并确认，会从全部美化中删除该标签。

> 自动识别的颜色和头像标签可以手动调整，手动选择后以你的设置为准。

### 搜索和筛选

- 在搜索框输入美化名称或标签，然后点击 **查询**。
- 点击风格、主题、颜色或头像标签进行筛选；可同时选择多个标签。
- 点击已选标签可取消单项筛选，点击 **清空** 可恢复全部美化。

### 多文件导入

点击 SillyTavern 原有的美化导入按钮后，可以一次选择多个美化 JSON 文件。扩展会依次导入，重名或无效文件会自动跳过。
