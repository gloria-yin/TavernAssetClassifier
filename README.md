# ST 分类器

用于保存角色卡常用配置，并给 SillyTavern 美化添加标签和筛选。

## 角色卡分类器

打开一张角色卡后，在扩展设置中展开 **美化与角色绑定**。

### 保存分类

- **美化绑定**：切换到需要的美化后点 **添加**，无需命名；可以为同一张角色卡添加多个美化。
- **预设绑定**：先选好当前预设和条目顺序，再点 **保存**，输入一个方便识别的名称。
- **user 绑定**：先切换到需要的 user 名称和头像，再点 **保存**。
- **世界书绑定**：先启用需要的全局世界书和角色世界书，再点 **保存**。保存内容包含当前选择和世界书条目。
- 预设、user 和世界书绑定右侧可手动应用或删除；预设和世界书还可以用旋转箭头更新为当前配置。
- 美化绑定提供应用、删除和星标操作；点击应用会立即切换美化，星标决定切换角色卡时自动加载哪一个美化。

### 自动加载

点击绑定右侧的空心星标，即可把它标为当前角色卡的自动加载项；星标变为实心后生效。以后切换到这张角色卡时，会自动加载已标记的美化、预设、user 和世界书。

每一类只能标记一个自动加载项。再次点击实心星标即可取消。

### 角色卡关联

点击 **角色卡关联** 右侧的 `+`，可以从角色卡库添加关联角色。搜索框支持按角色名称筛选，点击角色卡即可添加。

关联添加成功后会弹出内容转移窗口，可以将当前角色卡的美化、预设、世界书或 user 信息合并到新关联的角色卡。目标卡已有内容不会被覆盖，也不会重复添加相同内容；世界书仅转移非角色绑定世界书中的条目，应用时也会保留目标卡自己的角色绑定世界书。

## 美化分类

在 SillyTavern 的美化选择区域可以看到以下 4 个按钮：

| 按钮 | 作用 |
| --- | --- |
| **保存** | 用当前界面设置覆盖保存正在使用的美化。 |
| **重命名** | 修改当前美化的名称。 |
| **另存为** | 把当前界面设置保存成一个新的美化，不覆盖原美化。 |
| **打标签** | 给当前美化添加、移除或管理标签，也可以收藏当前美化。 |

### 添加和删除标签

1. 选择一个美化，点击 **打标签**。
2. 在 **风格** 或 **主题** 中输入文字，按回车或点击 `+` 添加。
3. **颜色** 和 **头像** 标签会由扩展自动识别，也可以在标签窗口中手动选择。
4. 点击当前美化已有的标签，只会从当前美化移除；长按标签并确认，会从全部美化中删除该标签。

> 自动识别的颜色和头像标签可以手动调整，手动选择后以你的设置为准。

### 搜索和筛选

- 在搜索框输入美化名称或标签，然后点击 **查询**。
- 点击风格、主题、颜色或头像标签进行筛选；可同时选择多个标签。
- 点击已选标签可取消单项筛选，点击 **清空** 可恢复全部美化。

### 多文件导入

点击 SillyTavern 原有的美化导入按钮后，可以一次选择多个美化 JSON 文件。扩展会依次导入，重名或无效文件会自动跳过。
